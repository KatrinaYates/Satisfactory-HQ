# Satisfactory HQ

Your personal Satisfactory factory-campus project hub.

**Project status:** Tier 4, Phase 1: Master Planning.

## What this is
A static, pastel-themed website with a master roadmap, building briefs, planned blueprints, project decisions, and a dashboard. The design centers on a pink glass headquarters (workshop, accessible supply storage, observation deck), blue Iron Works, mint-green Assembly Hall, purple Steel Works, and elevated skybridges.

## Operating agreement
- The player plays Satisfactory and tells ChatGPT what changed.
- ChatGPT reads the current GitHub content before editing, updates the relevant roadmap, building briefs, blueprint statuses and decision journal, and commits the changes.
- Do not mark anything complete without the player's confirmation.
- This site is read-only: **there is no browser-only local storage, login or database.** GitHub is the source of truth.
- Changes are made on request in ChatGPT, not automatically in the background.
- Each update should preserve the design system and prior decisions while incorporating new progress.

## Publish with GitHub Pages (one-time)
In this repository, navigate to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save. The expected public URL is:
https://katrinayates.github.io/Satisfactory-HQ/

The repository is public; avoid adding private details.
